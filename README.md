# Parvez Siddiqui - Developer Portfolio

A personal portfolio website for Parvez Siddiqui, a Full-Stack Developer focused on practical web experiences, clean interfaces, and reliable application logic.

## About

This portfolio presents my transition from operations and customer support into full-stack web development. It highlights my technical toolkit, professional experience, education, certifications, and selected projects.

## Features

- Responsive portfolio layout for desktop and mobile
- Hero section with developer focus and role positioning
- About, skills, experience, projects, education, and contact sections
- Downloadable resume
- Direct links to GitHub, LinkedIn, email, and phone
- Accessible navigation and interactive mobile menu
- Custom favicon and visual developer workspace theme

## Built With

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
git clone https://github.com/par-vezsiddiqui/portfolio.git
cd portfolio
npm install
```

### Run locally

```bash
npm run dev
```

Open the local URL shown in your terminal.

### Build for production

```bash
npm run build
```

### Lint the project

```bash
npm run lint
```
